Full Stack Open – Submissions

This repository contains my submissions and exercises for the Full Stack Open course by the University of Helsinki.

The course focuses on modern web development, including React, Node.js, Express, and MongoDB.

Contents

Here, I will publish my solutions to exercises and assignments from the different parts of the course as I progress through the material.

Goal

The goal of this repository is to track my progress, practice full-stack development, and document my learning journey.
